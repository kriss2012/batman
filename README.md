<p>

<b>The Dark Knight Experience</b> is a visually stunning, immersive web application built to showcase the lore of Gotham City's protector.

This project combines cutting-edge web technologies, including <b>Framer Motion</b> for silky-smooth animations and the <b>HTML5 Canvas API</b> for interactive mouse-tracking hover effects.

From exploring Bruce Wayne's origins to delving into the psychological profiles of his most notorious Rogues Gallery, the site is designed to feel cinematic, responsive, and alive.

</p>

<p>

Want to run the <b>Dark Knight Experience</b> on your own machine?

Follow these simple steps.

</p>

<h3>1️⃣ Clone the Repository</h3>

```bash
git clone https://github.com/kriss2012/batman.git

cd batman/vite-project
```

<br>

<h3>2️⃣ Install Dependencies</h3>

```bash
npm install
```

<br>

<h3>3️⃣ Start Development Server</h3>

```bash
npm run dev
```

<br>

<h3>4️⃣ Open in Browser</h3>

```text
http://localhost:5173
```

<hr>

<div align="center">

<img src="https://capsule-render.vercel.app/api?type=rect&height=90&text=🌐%20Deployment%20Guide&fontSize=34&color=gradient"/>

</div>

<details>

<summary>

<b>🚀 Deploy on GitHub Pages (Click to Expand)</b>

</summary>

<br>

<h3>1️⃣ Update <code>vite.config.js</code></h3>

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  base: '/batman/',
})
```

<br>

<h3>2️⃣ Install gh-pages</h3>

```bash
npm install gh-pages --save-dev
```

<br>

<h3>3️⃣ Update package.json</h3>

```json
"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d dist"
}
```

<br>

<h3>4️⃣ Deploy</h3>

```bash
npm run deploy
```

<br>

<h3>5️⃣ Configure GitHub Pages</h3>

<ul>

<li>Go to <b>Settings → Pages</b></li>

<li>Select <b>Deploy from a branch</b></li>

<li>Select the <b>gh-pages</b> branch</li>

<li>Click <b>Save</b></li>

<li>Wait 1–2 minutes for deployment.</li>

</ul>

</details>
